# Mars Sandbox

A browser sandbox game about a Mars outpost. Explore Mars with your rover, build your base and keep it running for 7 sols.

## Play 
Open `index.html` in any modern browser. No install and no build step.or paste this link https://tech1231000357.github.io/mars-sandbox/ in any browser.

## Tech 

Plain JavaScript and the HTML5 Canvas 2D API in a single file, with no engine and no dependencies.

## Features

- Base building with power, oxygen, water and food simulation
- Rovers, expeditions and outposts across real regions of Mars
- Two crew members with a random origin, name and profession who walk between modules, sleep at night and get sad when supplies run low
- Weather, dust storms, radiation and a technology tree with puzzles
